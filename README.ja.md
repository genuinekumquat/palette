# TeamProject2 — クラス予約プラットフォーム

[한국어](README.md) | **日本語**

ホストがワンデークラスを登録し、ゲストが予約・決済するWebサービスです。
IT専門学校（itwillbs）のチームプロジェクトとして始まり、ポートフォリオ整理のために
**Eclipse Dynamic Web Project → Mavenプロジェクト**へ移行しました。

## 技術スタック

| 区分 | 使用技術 |
|------|------|
| 言語 | Java 11+（ビルド/テストは JDK 21） |
| Web | Servlet 3.1 · JSP（scriptlet）、MVC 2 パターン |
| DB | MySQL 8.x、JDBC + JNDI DataSource |
| WAS | Apache Tomcat 9（javax.* 名前空間） |
| ビルド | Maven（war） |

## アーキテクチャ

```
controller (HttpServlet)  ─▶  service  ─▶  dao (JDBC)  ─▶  MySQL
        │                                     ▲
        └────────────  domain (DTO) ──────────┘
url-pattern: *.me *.cbo *.nbo *.rbo *.qbo *.re *.pa *.se  (web.xml)
```

## コード復元について

このリポジトリにはプロジェクト期間（2023.08 〜 2023.09）の途中時点のコードしか残っておらず、
最終完成版は消失しました。2026年10月、ポートフォリオ整理の過程で
**当時のポートフォリオ資料（機能説明、画面キャプチャ、コードキャプチャ）をもとに担当機能を書き直しました**。
復元作業はAIコーディングツール（Claude Code）の支援を受けて行いました。

したがって、下表の「復元」コードは **2023年のオリジナルコードではなく、同じ機能を再現したコード**です。

### プロジェクト後の改善点

- **ID・パスワード検索の認証問題**（`1e07daf`）
  本人確認の結果をログイン用セッション値（`memberId`）に保存していたため、氏名・メールアドレスさえ分かれば
  パスワードなしでログイン状態になってしまう問題を修正しました。パスワード再設定も、フォームから送られたIDではなく
  サーバー側で本人確認済みのID（`resetId`）のみを変更するようにしました。
- **クラス編集が保存されない問題**（`1103d39`）
  編集フォームが `classNum` を送信しておらず、`where classNum=0` で実行されていた問題を修正しました。
- **削除後の遷移先URLの誤り、存在しないクラスへのアクセス時の500エラー**（`52d6d6e`）

復元・改善の履歴は `master` のコミット履歴（`611dc86` 〜 `29d8a29`）で機能ごとに確認できます。

## ローカル実行方法（IntelliJ IDEA Ultimate）

### 1. データベースの準備

```bash
mysql -u root -p < src/main/sql/schema.sql
```

`teamproject2` データベースとテーブル、サンプルデータが作成されます。
サンプルアカウントは `guest01`、`guest02`、`host01` で、パスワードはすべて `1234` です。
（`guest01` は1番クラス、`guest02` は2番クラスに決済済みの予約があるため、レビューを書けます。）
元のDBダンプが消失したため、スキーマはDAO層から逆算して再構成したものです。

### 2. DataSource 認証情報の設定

`src/main/webapp/META-INF/context.xml` の `password="CHANGE_ME"` をローカルMySQLの
パスワードに変更します。（実際のパスワードはコミットしません。）

### 3. Tomcat 実行構成の追加

1. **Run ▸ Edit Configurations ▸ + ▸ Tomcat Server ▸ Local**
2. **Application server**：Tomcat 9 のインストールパスを指定（なければダウンロード）
3. **Deployment** タブ：`TeamProject:war exploded` アーティファクトを追加、
   **Application context** = `/TeamProject`
4. **Run** — ブラウザで `http://localhost:8080/TeamProject/` を開く

> MySQL JDBC ドライバーは `pom.xml` の依存関係としてWARに含まれるため、Tomcat の `lib` に
> 別途配置する必要はありません。

### コマンドラインでのビルド

```bash
mvn clean package      # target/TeamProject.war
```

## 既知の問題（整理予定）

- `NoticeBoardDAO`：`update notice set = noticeReadcount+1 ...` などのSQL構文エラー
- `NoticeBoardDAO.updateBoard`：`where num=?` — 存在しないカラム
- `MemberDAO.insertHost`：ゲスト用のINSERTを再利用しているため、`businessNum` が `memberLocation`
  カラムに保存される
- パスワードが平文で保存されている（ハッシュ化未適用）
- `reserve` / `payment` / `question` / `searchlog` のサービス・DAOロジックの再実装が必要（コード消失分）
